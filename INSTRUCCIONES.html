Su página de exámenes,
lista para GitHub Pages.

  1. Extraiga el ZIP. Suba el contenido extraído, incluyendo las carpetas.
  2. Abra su repositorio. Pulse Add file → Upload files y arrastre todos los archivos. El archivo index.html debe quedar junto a las carpetas assets, data y pdfjs.
  3. Guarde. Pulse Commit changes.
  4. Active la página. Abra Settings → Pages. Seleccione Deploy from a branch, la rama main y /(root). Pulse Save.
  5. Comparta el enlace. Cuando GitHub termine, el enlace aparecerá en esa misma sección de Pages.
Para las mamás: entrar con el ID de la tarjeta → Consultar exámenes → Repaso → Ver examen. El botón Ver fotos abre directamente las hojas fotografiadas.

Lo que ya viene incluido

27 expedientes, 24 PDF completos con fotos, 3 reportes pendientes, acceso por ID, opción de recordarlo y visor adaptable al celular con botones para ampliar y pasar de hoja.

Los expedientes y PDF van cifrados. El ID funciona como llave; cualquier persona que lo conozca podrá abrir ese expediente. Esta versión no tiene cuentas privadas en un servidor.

Para usar la consulta, abra el enlace HTTPS publicado. Mantenga todos los archivos juntos y conserve sus nombres. Esta exportación es independiente de la app y requiere una nueva exportación para añadir exámenes.
